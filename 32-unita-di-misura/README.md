# Le unità di misura

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- px: bordi e dettagli; rem: testo e spazi
- em: il testo dell'elemento; in font-size, del genitore
- ch: le righe; %: il contenitore; vw e vh: la finestra
- Altezza piena, anche sui telefoni: min-height: 100dvh

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
