# Flexbox completo

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- display: flex e flex-direction: row oppure column
- justify-content, align-items e align-self per allineare
- gap per lo spazio, flex-wrap: wrap per andare a capo
- flex: 1 1 400px, crescita, restringimento e base

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
