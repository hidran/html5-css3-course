# Il box model e box-sizing

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- Quattro strati: contenuto, padding, border, margin
- content-box: padding e border si sommano a width
- border-box: width è la larghezza fino al bordo
- Il reset: * { box-sizing: border-box; } in cima al foglio

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
