# Variabili CSS

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- Si definisce in :root: --color-accent: royalblue;
- Si usa con var(--color-accent), anche dentro un valore
- Ridefinita in .featured: la scheda e ciò che contiene
- @property (da luglio 2024): tipo e riserva; :root resta

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
