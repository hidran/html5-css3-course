# position: sticky

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- position: sticky resta nel flusso, poi si ferma alla soglia
- Senza una soglia l'elemento non si ferma
- top: 0 per l'intestazione, top: 84px per il riquadro
- Stessa soglia: gli elementi si sovrappongono

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
