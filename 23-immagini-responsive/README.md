# Immagini responsive

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- srcset e sizes: più copie, sceglie il browser
- picture e source con type: AVIF, e img di riserva
- width e height: lo spazio è già riservato
- loading="lazy" rimanda, fetchpriority="high" anticipa

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
