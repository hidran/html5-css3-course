# Trasformazioni

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- Le trasformazioni non spostano gli altri elementi
- translate sposta, rotate ruota, scale ingrandisce
- transform: una lista sola, hover la sostituisce intera
- transition: scale 300ms, translate 300ms;

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
