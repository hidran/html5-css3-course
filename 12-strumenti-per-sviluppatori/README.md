# Gli strumenti per sviluppatori del browser

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- Elements: l'HTML come il browser l'ha letto
- Styles: il nostro file con la riga, e lo user agent stylesheet
- Barrata = ha perso; qui ha vinto il nostro file
- Computed: valori finali e scatola; le correzioni nel file

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
