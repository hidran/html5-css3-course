# Selettori moderni: :is(), :where(), :has()

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- :is(header, .banner, footer) a: una lista, un selettore
- :where(): come :is(), ma con peso zero
- .card:has(.badge): la scheda che contiene l'etichetta
- a:focus-visible: un outline per chi usa la tastiera

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
