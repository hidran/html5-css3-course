# Ombre e filtri

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- text-shadow: 2px 2px 4px black;
- box-shadow: più ombre, separate da una virgola
- filter: grayscale(100%) sull'elemento
- backdrop-filter: blur(8px), da settembre 2024

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
