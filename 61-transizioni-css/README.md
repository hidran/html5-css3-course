# Transizioni CSS

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- transition: background-color 2s, box-shadow 2s;
- Nella regola di base: vale all'andata e al ritorno
- Il ritmo: ease, linear, ease-in, ease-out
- Pochi decimi di secondo; meglio opacity e transform

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
