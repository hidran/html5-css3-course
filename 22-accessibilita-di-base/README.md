# Accessibilità di base

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- lang, header, nav, main, footer, titoli in ordine
- alt descrive l'immagine; alt="" se è solo decorativa
- <label for="email"> e <input id="email">
- Tab, contorno del focus, link per saltare al contenuto

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
