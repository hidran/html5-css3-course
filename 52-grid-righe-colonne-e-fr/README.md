# CSS Grid: righe, colonne e fr

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- display: grid e grid-template-columns per le colonne
- fr divide lo spazio libero, repeat() ripete una misura
- grid-auto-rows: minmax(100px, auto) per le righe
- gap: lo spazio tra righe e colonne

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
