# CSS Grid: aree con nome

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- grid-area: il nome dell'area di ogni elemento
- grid-template-areas: la griglia disegnata, un testo per riga
- Lo stesso nome ripetuto: l'area occupa più celle
- grid-template-rows: auto 1fr auto per le righe

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
