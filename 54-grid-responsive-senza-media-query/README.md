# CSS Grid: griglie responsive senza media query

La pagina di questa lezione del corso HTML5 e CSS3, com'è alla fine del video.

## In questa lezione

- repeat(auto-fill, ...): le colonne le conta il browser
- minmax(200px, 1fr): un minimo, poi parti uguali
- auto-fit: le colonne vuote si chiudono
- Nessuna media query

## Come aprirla

Scaricate la cartella e aprite `index.html` nel browser. Per modificarla, aprite la cartella in Visual Studio Code.
